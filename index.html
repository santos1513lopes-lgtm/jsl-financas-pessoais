Sem senha e sem backup JSON, não é possível recuperar os registros. Guarde seu backup em local seguro.

Backup e segurança dos dados

Os dados ficam salvos e criptografados neste navegador. Para atualizar outro computador ou celular, baixe o backup JSON mais recente e restaure o arquivo no outro aparelho. A restauração substitui todos os registros atuais; não combina dados.

O backup JSON contém seus dados financeiros sem senha. Faça backups periódicos e guarde o arquivo em local seguro. Limpar os dados do navegador pode apagar os registros salvos neste dispositivo.
